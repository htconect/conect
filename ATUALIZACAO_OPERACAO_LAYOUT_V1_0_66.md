# Connect 1.0.66 — Operação

- **Parada na loja** passa a ter o mesmo padrão visual dos botões **Sincronizar Google** e **Calcular tempo**.
- **Equipe tempo** foi renomeado visualmente para **Deslocamento**.
- **Tempo de chegada** foi renomeado visualmente para **Chegada**.
- Nenhuma regra de cálculo foi alterada; permanecem os parâmetros e o recálculo da versão 1.0.65.

# Atualização InfinitePay v1.0.6

## Regras de reabertura do link

1. Sem pagamento e sem checkout criado: cliente escolhe Sinal ou Valor integral.
2. Sem pagamento e com checkout já criado: o mesmo checkout é reutilizado.
3. Com pagamento parcial: o cliente vê somente o saldo restante.
4. Com checkout do restante já criado: o mesmo checkout do restante é reutilizado.
5. Quitado: não existe nova cobrança.

## E-mail

O e-mail pode ser configurado como visível e obrigatório por empresa. A obrigatoriedade vale para novos envios. Clientes/contratos legados sem e-mail continuam abrindo normalmente e podem completar o dado quando fizerem uma nova edição ou novo pré-contrato.

# CONNECT 1.0.90

## Padronização visual e fluxo financeiro

- Operação passou a ter uma única fonte de CSS para os cards de abertura.
- Equipamentos ficam alinhados à esquerda e com maior hierarquia visual que Recursos.
- Mantido o menu estilo app no celular.
- Categorias dos lançamentos bancários agora são salvas em lote pelo botão **Salvar categorias**.
- Alterações ainda não salvas são destacadas em âmbar, sem usar vermelho de erro.
- Removido o botão de confirmação individual das categorias do extrato.
- Excel e PDF receberam ícones e dimensões compatíveis com o botão Importar.
- Evolução Financeira foi reorganizada como dashboard executivo, com KPIs do ano, comparação anual e gráfico mensal mais limpo.
- Nenhuma regra de cálculo financeiro, vínculo, contrato ou operação foi alterada.

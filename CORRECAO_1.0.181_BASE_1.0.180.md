# Conect 1.0.181 – Correção do pacote regressivo

Este pacote foi reconstruído **a partir da versão 1.0.180**, preservando os ajustes de opcionais entre empresas, estoque, configurações de brindes, financeiro e ativação inicial da Karaokê RJ/Viviokê.

A versão 1.0.181 fornecida anteriormente foi criada por engano a partir da base 1.0.177 e perdeu mudanças de código. **Não use o ZIP 1.0.181 anterior.**

Desta base 1.0.180 foram incorporados APENAS os recursos de diagnóstico da Agenda: logs detalhados para falhas de sincronização de contrato e exibição dos motivos de falha na Agenda; versão corrigida para 1.0.181.

Esta é uma correção de regressão e diagnóstico, não é uma correção comprovada da causa raiz da falha de sincronização com o Google. Fazer backup de banco antes do deploy, validar em homologação e testar os módulos.

# NFS-e por empresa — v1.0.32

A integração com o Organiza agora depende de `Empresa.nfse_ativa`.

- `true`: o contrato exibe o botão para gerar NFS-e no Organiza.
- `false`: o bloco não é exibido e a rota bloqueia a geração.
- Migração de produção: habilita somente Karaokê RJ quando a coluna é criada pela primeira vez.

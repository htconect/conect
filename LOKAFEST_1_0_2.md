# LokaFest 1.0.2

- Integra login do LokaFest ao Humiat ID sem alterar a senha local existente.
- Localiza o participante por CPF e, como contingência, WhatsApp.
- Adiciona API privada de resumo para o painel Humiat.
- Resumo inclui total global de indicações, recebidas, repassadas, prioridades e participação no grupo de locadores.
- Informa situação do pacote musical: atualizado, a um pacote do bloqueio ou bloqueado.
- Usuário sem cadastro local é direcionado para concluir o cadastro do LokaFest.
- Adiciona variável opcional `LOKAFEST_GRUPO_WHATSAPP_URL` para o botão do grupo.

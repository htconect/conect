# v1.0.27 — Checkout Humiat pré-preenchido

A compra de Humiats passa a enviar o bloco `customer` para a InfinitePay, usando nome, e-mail e WhatsApp do comprador logado. Os dados são editáveis na tela e persistidos no perfil. A grade dos pacotes foi refeita para responder à largura disponível, evitando cartões estreitos, valores quebrados e botões fora do padrão.

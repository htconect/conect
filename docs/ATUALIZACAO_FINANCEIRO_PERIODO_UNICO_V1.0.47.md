# v1.0.47 — Financeiro

Ajustes de usabilidade e competência mensal:

- mês/ano superior controla toda a tela;
- período inferior inicia com o mês completo e só aceita dias dentro desse mês;
- filtros sem botões Filtrar/Limpar, com atualização automática;
- semana é alterada por mudança de data ou ação do usuário;
- A pagar deixa de trazer saldos vencidos de meses anteriores na consulta do mês;
- edição de conta a pagar manual com proteção para baixas já realizadas;
- cálculo de saldo bancário não foi alterado.

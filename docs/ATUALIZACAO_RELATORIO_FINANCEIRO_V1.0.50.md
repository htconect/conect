# v1.0.50 — Relatório financeiro alinhado aos cards

O relatório mensal (PDF/Excel) consultava todos os registros de Solicitação do período, enquanto os cards da tela exibiam somente contratos aprovados.

A partir desta versão, ambos usam `STATUS_CONTRATO_APROVADO`, eliminando diferenças de quantidade, valor total, recebido e saldo a receber entre tela e relatório.

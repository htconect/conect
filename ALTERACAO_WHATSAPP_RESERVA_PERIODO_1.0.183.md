# Conect 1.0.183 — Compartilhar reserva por período no WhatsApp

- Alterado botão "Criar link" para "Compartilhar pelo WhatsApp".
- Servidor mantém as validações de estoque e datas, cria o link individual e redireciona para o WhatsApp com mensagem pronta, sem número pré-definido.
- Mensagem contém empresa, produto, datas, tipo, valor fechado e URL personalizada.
- A reserva não é feita no WhatsApp: cliente abre o link e conclui pelo Conect.
- Nenhuma mudança de banco de dados.
- Caso o usuário queira obter o link sem abrir WhatsApp, poderá ser adicionado botão secundário em melhoria futura.

# Integração NFS-e Connect → Organiza — v1.0.31

- Adiciona botão **Gerar NFS-e no Organiza** no contrato/reserva.
- O Connect envia somente dados operacionais do contrato: cliente, datas, endereço do evento, equipamentos e valor total.
- Nenhuma regra fiscal (CTN, NBS, ISSQN, IBS/CBS) fica no Connect.
- O Organiza continua responsável por transformar o rascunho em NFS-e.
- A URL do Organiza pode ser configurada por `ORGANIZA_NFSE_URL`.

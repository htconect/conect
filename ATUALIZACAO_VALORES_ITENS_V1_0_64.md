# Connect 1.0.64 — proteção dos valores manuais dos itens

- O valor base do equipamento passa a ser apenas uma sugestão para linhas novas ou zeradas.
- Selecionar/trocar um produto não substitui mais um valor unitário manual já preenchido.
- O editor completo não sobrescreve o primeiro item quando a reserva possui vários itens.
- Em contratos com múltiplos itens, o subtotal comercial é calculado pela soma dos itens existentes.
- Valores manuais de cada item permanecem sob controle do usuário.

## Versão

`1.0.64`
